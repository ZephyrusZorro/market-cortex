# ADR 0003: Typescript React Frontend

**Status:** Accepted for Phase 0.5 architecture freeze · 2026-09-26  
**Baseline:** [Phase 0 Blueprint](../architecture/PHASE_0_BASELINE_2026-09-26.md) · [review](../architecture/ARCHITECTURE_REVIEW.md)

## Context
A responsive typed workstation is planned after data foundation.

## Decision
TypeScript/React web client behind versioned APIs.

## Alternatives
Server templates, desktop-native UI.

## Consequences
Broad ecosystem and code separation; build tooling overhead.

## Reconsideration triggers
Offline desktop constraints or measured UI performance issues.
