# Ports and Feed Evolution

**Baseline:** [Phase 0 §§5–6](PHASE_0_BASELINE_2026-09-26.md), [ADRs 0008–0009](../DECISION_LOG.md). Interface sketch only, no adapters or event bus implementation.

`MarketDataProvider.capabilities() -> ProviderCapability[]`; `resolve_native(identifier, venue, as_of) -> mapping candidates`; `fetch(kind, instrument_or_series_id, [start,end), resolution, cursor?, adjustment_request?) -> page<raw_ref, native_record, next_cursor, source_times, rights>`; later `subscribe(kind, identities, cursor?) -> stream<raw_ref, native_record, native_sequence, checkpoint>`. Phase 1 calls only `fetch(kind=Bar, resolution=P1D)`. A provider advertises supported kinds, resolutions, adjustment and publication semantics separately. An unsupported request returns a typed capability error, not an empty dataset. Native symbols never escape the adapter as primary keys.

`ObservationStore.append(batch, envelopes, validation) -> immutable_manifest_candidate`; `ManifestCatalog.publish(candidate, expected_parent) -> manifest_id`; `ObservationQuery.read(kind, identity, range, as_of, manifest_id, selection_policy) -> observations+coverage`; `ArtifactStore.put(bytes, rights) -> hash/ref`. These are domain ports; implementations can use PostgreSQL+Parquet now and other time-series engines later. Query always pins manifest, respects available time, rights and quality; no file-path API contract. Dataset pointer publication is a DB transaction after file durability, with orphan scanner for failed transactions.

`EventPublisher.publish(outbox_record)` and `EventConsumer.handle(event, idempotency_key)` share the versioned `DomainEvent` envelope. Phase 1 database outbox supports at-least-once delivery; future broker preserves event IDs and semantics. Stream provider checkpoints are distinct from committed internal events. Market record sequence gaps (particularly book deltas) require quarantine/resnapshot, not ordinary bar dedup.

**Physical layout:** Phase 1 Parquet buckets by observation kind, venue, event month and bounded instrument group; manifest records exact members and statistics. A later high-volume tick/book feed may bucket by venue/kind/day/hour and instrument shard. Derivative contracts add expiry/underlying/type indexed fields; contracts are not encoded in filenames as global identity. Economic series can use a different kind-specific layout. Schema registry is versioned; additive fields are optional only when semantics permit, and breaking changes require migration/new version. None of these future feeds is ingested in Phase 0.5.
