# Data Source Matrix — researched 2026-09-26

**Status:** documentation-screened candidates, not authenticated or licensed production feeds. PRIMARY/FALLBACK/FUTURE PREMIUM are recommendations for **feasibility probes**, not installed adapters. Source contracts, price, rights and exact symbol depth must be confirmed in the owner's account. No undocumented scraping. [Pilot universe](PILOT_UNIVERSE.md), [readiness](../planning/READINESS.md).

Abbreviations: D daily, I intraday, S streaming; `?` means documentation does not establish the required property. Historical depth is coverage advertised/documented, **not** proof that every pilot symbol has that depth. Timestamp/adjustment verification is mandatory per selected endpoint. Costs are tier descriptions rather than potentially stale price quotes.

## Selection protocol

1. Record exact provider product and terms/retention; obtain credentials privately. 2. Resolve each candidate through official catalog; store venue and native ID with valid-time interval. 3. Probe earliest/latest daily rows, holiday, split, ticker change and correction; compare provider semantics. 4. Confirm rate/price/storage budget for one year and local backup. 5. Mark source `supported` only after tests; otherwise defer/label proxy. Product and account claims are not inferred from a marketing page.
